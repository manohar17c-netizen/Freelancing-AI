# Free hosting via Netlify

Import `manohar17c-netizen/Freelancing-AI` on https://app.netlify.com/start using GitHub. Choose branch `main` **after this pull request is merged** (or choose `feature/hrms-ai-demo` for a preview). Configure Base directory: `hrms-ai-demo`; Build command: leave blank; Publish directory: `.` (the base directory). Netlify will issue an actual `*.netlify.app` link after successful deployment. No paid hosting, API key or backend is necessary for this fictional static concept demo. The existing `Freelancing-AI` app is unrelated and remains untouched.
